# Inventory Management System

A PostgreSQL-based inventory management system for a footwear business.

## Features

- Product management (basic product details)
- Product variants (size and colour)
- Inventory tracking (current inventory details, when it was created, when it was updated)
- Purchase management (purchase date, invoice number, total_bill_amount)
- Sales management (sale date, billed amount, discount offered)
- Supplier management (supplier details)
- Customer management (customer details)

## Technologies

- PostgreSQL
- SQL
- Git
- GitHub
